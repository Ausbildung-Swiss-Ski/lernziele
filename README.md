# Lernziele Talent vs. Leistungssport (Leseversion)

Leseversion der Lernziele von Swiss-Ski Ausbildung & Entwicklung für die Module
**Off-Snow**, **Coaching** und **On-Snow** – eingebunden im FEA-Portal (Bereich Ausbildung).

- Seite: https://ausbildung-swiss-ski.github.io/lernziele/ (`?m=offsnow`, `?m=coaching`, `?m=onsnow`)
- **Bearbeitet wird nicht hier**, sondern in den drei Lernziel-Seiten auf claude.ai (gemeinsame Datenbank).
  Dort schreibt der Knopf «Leseversion aktualisieren» `index.html` und `data/<modul>.json` in dieses Repo
  (über die GitHub-Verbindung der Person, die den Knopf drückt).
- Hier nichts von Hand ändern – es wird beim nächsten Aktualisieren überschrieben.

## Aufbau

```
index.html          Leseversion (gleiche Oberfläche wie die Bearbeitungsseiten, ohne Bearbeiten)
data/offsnow.json   Inhalte Off-Snow
data/coaching.json  Inhalte Coaching
data/onsnow.json    Inhalte On-Snow
```
